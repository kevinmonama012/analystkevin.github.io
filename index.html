Formula reference

02 / tap a tab, then a card
Pip value
position sizing
▼
Pip Value = (Pip Size / Exchange Rate) × Lot Size
So what: the number every lot-sizing decision on XAU/USD depends on — get this wrong and your risk-per-trade is wrong too.
Risk-reward ratio
R:R
▼
R:R = (Entry − Stop Loss) : (Take Profit − Entry)
So what: the filter that decides whether a setup is worth taking before a single dollar is risked.
Position size
lot sizing by risk %
▼
Lot Size = (Account × Risk%) / (Stop Loss Pips × Pip Value)
So what: turns a fixed risk % into an exact lot size, so every trade risks the same share of the account regardless of stop distance.
Max drawdown
EA risk profile
▼
Max DD = (Peak Equity − Trough Equity) / Peak Equity
So what: the number that decides whether a backtest is actually tradeable with real capital, or just looks good on paper.
Expectancy
system edge
▼
Expectancy = (Win% × Avg Win) − (Loss% × Avg Loss)
So what: the single number that proves whether an EA has a real edge over hundreds of trades, not just a lucky streak.
EBITDA
profitability, pre-financing
▼
EBITDA = Net Income + Interest + Taxes + Depreciation + Amortization
So what: strips financing and accounting noise so operating performance compares cleanly across periods.
CAGR
compound annual growth rate
▼
CAGR = (End Value / Start Value)^(1/years) − 1
So what: smooths volatility into one honest growth number.
Z-score
outlier detection
▼
z = (x − μ) / σ
So what: flags data points worth investigating before a model or dashboard is built on top of them.
Pearson's r
correlation coefficient
▼
r = Σ[(xᵢ−x̄)(yᵢ−ȳ)] / √[Σ(xᵢ−x̄)²·Σ(yᵢ−ȳ)²]
So what: confirms two metrics (e.g. DXY vs XAU) actually move together before betting a strategy on it.
ROI
return on investment
▼
ROI = (Net Return / Cost) × 100
So what: the deciding number in almost every "keep funding this" conversation.
